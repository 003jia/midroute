# MR-012（部分）结构化错误分类 验收证据（P0-3）

> 日期：2026-09-14
> 范围：MR-012 中继事件合约与流式可靠性——结构化上游错误分类（ISS-09）

## 一、实现内容

- `internal/connectors` 新增结构化错误：
  - 哨兵错误：`ErrRateLimited`、`ErrAuth`、`ErrTimeout`、`ErrNetwork`、`ErrTruncated`、`ErrModelUnavailable`、`ErrUpstream`、`ErrQuotaExhausted`。
  - `UpstreamError{Kind,Status,Body,Err}` 实现 `Unwrap`/`Is`，支持 `errors.Is/As`。
  - `Classify(status, err)`：按 HTTP 状态与底层错误归类（429/401/403/404/5xx/超时/网络）。
  - `Retryable(err)`：基于 `errors.Is` 的可重试判定（429/超时/网络/截断/5xx；鉴权/404 不可重试）。
- `httpclient.go` 的 `readJSON/readBytes/consumeSSE` 非 2xx 统一返回 `ClassifyWithBody`（携带脱敏响应体）。
- `openai/anthropic/gemini` 连接器改用 `Classify` 与 `ErrTruncated`，删除 `classifyUpstreamError` 字符串函数。
- `router.safeToRetry` 改为 `connectors.Retryable(err)`（移除 `strings.Contains`）。
- `api.mapRelayError` 改为 `errors.Is` 分支（含 `ErrTimeout`→网关超时、`ErrTruncated`、`ErrQuotaExhausted`）。
- `accounts.statusFromErr` 改为 `errors.Is`（`ErrAuth`→permission_required，`ErrRateLimited`→unknown）。
