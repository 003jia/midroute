## 遗留 / 边界
1. `/v1/models` 也要求令牌（列表模型需持有效项目令牌）。
2. OAuth 后台回调路径与手动 complete 并发时先到先得（`fl.status` 判重）；后台路径完成的账户创建经同一 `completeFlowAccount`。
3. Responses 会话绑定 TTL 固定 24h（上游实际时效未知，工程默认）；WebSocket/后台响应未实现（协议层显式不支持，透传请求中这些字段交上游判定）。
4. 并发上限为进程内存态（单进程部署语义），多实例需外部存储。
5. Codex 真实调用、真实 OAuth 授权仍待真实凭据（MR-013 第 3 条 / MR-007 真实验收）。
