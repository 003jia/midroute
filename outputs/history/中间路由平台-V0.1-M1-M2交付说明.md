## M1：集成仓库与可重复构建 ✅

| 交付物 | 位置 | 说明 |
|---|---|---|
| 集成仓库 | 仓库根（`git init -b main`） | 自有代码与上游分离；`work/` 上游克隆不入库，仅 `PINNED_COMMITS` 记录冻结 |
| 一键构建 | `build/build.sh` | 三个上游构建 + 自有工具 → `dist/`，输出 `MANIFEST.txt`（含冻结提交） |
| 冒烟测试 | `build/smoke-test.sh` | 三服务启动 + 鉴权/模型/健康/管理台端点断言 |
| 上游同步评估 | `build/sync-upstream.sh` | dry-run 展示差异（提交数/摘要/涉及文件），`apply` 前需人工评审 |
| 密钥扫描门禁 | `build/ci/secret-scan.sh` | 扫描仓库内疑似密钥模式，CI/提交前执行 |
| 本地运行 | `build/run-local.sh` | 中文引导输出，默认仅监听 127.0.0.1；管理台启用 loopback 免密，网关随机生成访问 Key |
| OneAPI 接入 | `work/one-api`、`build/oneapi-sync.sh` | 冻结官方仓库，独立端口/SQLite，自动将本地 CLIProxyAPI 注册为 OpenAI-compatible 渠道 |

OneAPI 保留官方仓库结构与 MIT 许可，仅增加两个本地运行开关：`APPROXIMATE_TOKEN_ENABLED` 和 `SKIP_TIKTOKEN_INIT`。`run-local.sh` 默认开启它们，避免离线环境因远程 tiktoken 文件下载阻塞启动；未设置时仍保持上游精确 token 统计路径。

验证：`./build/build.sh && ./build/smoke-test.sh` 全绿；自有模块 `go test ./internal/...` 通过。

## M2：自有模块 ✅（独立实现，尚未接线进上游）

| 模块 | 包/工具 | 能力 | 对齐计划 |
|---|---|---|---|
| G3 Keychain/Vault | `internal/vault` / `cmd/vaultctl` | macOS Keychain 存取；仅存 SecretRef（服务/账号/指纹）；日志与 URL query 脱敏；Secret 用后清零 | §6.2 Credential Vault、§10 |
| G1 健康/拥挤度评分 | `internal/health` / `cmd/healthcheck` | TTFT/Latency P50/P95、429/5xx/超时率、评分 0-100、故障分类（account_limited / provider_degraded / model_busy_inferred / network_issue）、置信度（样本量）、滞回与熔断、小样本不自动切换 | §6.5、US-004 |
| G2 官方账单对账 | `internal/billing` / `cmd/billingcheck` | OpenAI/Anthropic 组织 Usage/Cost 读取（httptest 可测），Gemini 明确 unsupported；来源（official/observed/estimated/manual）与可信度（exact/reported/estimated/unavailable）；官方与本地观测分列对账不求和；无凭据 dry-run | §6.4、US-003、§9 |
| G6 中文产品化 | `README.md`、`docs/首次配置向导.md`、`build/run-local.sh` | 中文信息架构、首次配置向导、localhost 默认、安全提示 | FR-16、§5 |

补充发现：CPA-Manager-Plus 上游已内置 i18n（含 `zh-CN`），G6 的 UI 层工作量因此更低。

## 如何使用

```bash
./build/build.sh                      # 构建
./build/smoke-test.sh                 # 冒烟
./build/run-local.sh                  # 本地运行（127.0.0.1）
./dist/bin/vaultctl store openai conn-default   # Keychain 存凭据（stdin 输入）
./dist/bin/healthcheck < samples.json          # 健康评分
./dist/bin/billingcheck -provider openai -key 'sk-admin-...' -window-day 7
./build/sync-upstream.sh              # 上游升级评估（dry-run）
./build/ci/secret-scan.sh             # 提交前密钥门禁
```

> 说明：集成仓库已 `git init`，但本批次变更未提交，由仓库所有者确认后再提交。
